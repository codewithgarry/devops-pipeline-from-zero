# Audit your own pipeline

Tick each line for your project. Every unticked line is a video in this course.

- [ ] Every push runs the tests, and a red test blocks the merge (videos 9, 10)
- [ ] The image is built by CI, never on a laptop (video 11)

- [ ] CI is cached and takes minutes, not tens of minutes (video 13)
- [ ] The image runs as a non-root user, from a slim base (video 5)
- [ ] Configuration comes from the environment, not from the code (video 6)
- [ ] What runs in the cluster is what git says (GitOps, videos 16, 17)
- [ ] A crashed pod comes back on its own (video 18)
- [ ] A bad release is undone with one git revert (video 19)
- [ ] The app exposes metrics, and a dashboard shows them (videos 20, 21)
- [ ] An alert pages a person when users are hurt (video 22)
- [ ] No secret is in git (video 23)
